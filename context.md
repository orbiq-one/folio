# UI terminology and layout defaults

## Use these terms

- **Sidebar**: the left pane.
- **List** or **email list**: the middle pane that contains email rows.
- **Composer pane**: the right pane. Use this term when the pane displays a message, a reading view, or an empty state.

## Adaptive layout defaults

- Sidebar: 240 pt.
- Email list: 380 pt.
- Composer pane: the remaining available width.
- Keep pane boundaries as native resizable dividers. These values are defaults, not fixed widths.
